# 保健師助産師看護師法施行令 新旧対照表

| 条数 | 旧規定 | 新規定 |
| :--- | :--- | :--- |
| 第三条 | **第三条 （登録事項の変更）**<br> 保健師又は看護師は、前条第一項第二号又は第三号の登録事項に変更を生じたときは、三十日以内に、保健師籍又は看護師籍の訂正を厚生労働大臣に申請しなければならない。<br>２ 助産師は、前条第一項第二号の登録事項に変更を生じたときは、三十日以内に、助産師籍の訂正を厚生労働大臣に申請しなければならない。<br>３ 准看護師は、前条第二項第二号の登録事項に変更を生じたときは、三十日以内に、免許を与えた都道府県知事に准看護師籍の訂正を申請しなければならない。<br>４ 前三項の申請をするには、申請書に申請の事由を証する書類を添えなければならない。<br>５ 業務に従事する保健師、助産師若しくは看護師又は准看護師が第一項から第三項までの申請をする場合には、就業地の都道府県知事を経由しなければならない。 | **第三条 （登録事項の変更）**<br> 保健師又は看護師は、前条第一項第二号又は第三号の登録事項に変更を生じたときは、三十日以内に、保健師籍又は看護師籍の訂正を厚生労働大臣に申請しなければならない。<br>２ 助産師は、前条第一項第二号の登録事項に変更を生じたときは、三十日以内に、助産師籍の訂正を厚生労働大臣に申請しなければならない。<br>３ 准看護師は、前条第二項第二号の登録事項に変更を生じたときは、三十日以内に、免許を与えた都道府県知事に准看護師籍の訂正を申請しなければならない。<br>４ 前三項の規定による申請をする場合には、申請書に申請の事由を証する書類を添えなければならない。<br>５ 業務に従事する保健師、助産師若しくは看護師又は准看護師が第一項から第三項までの規定による申請をする場合には、就業地の都道府県知事を経由しなければならない。ただし、当該准看護師が情報通信技術活用法第六条第一項の規定により第三項の規定による申請を電子情報処理組織を使用して行うときは、当該就業地の都道府県知事を経由することを要しない。 |
| 第四条 | **第四条 （登録の抹消）**<br> 保健師籍、助産師籍又は看護師籍の登録の抹消を申請するには、厚生労働大臣に申請書を提出しなければならない。<br>２ 准看護師籍の登録の抹消を申請するには、免許を与えた都道府県知事に申請書を提出しなければならない。<br>３ 業務に従事する保健師、助産師若しくは看護師又は准看護師が前二項の申請をする場合には、就業地の都道府県知事を経由しなければならない。 | **第四条 （登録の抹消）**<br> 保健師、助産師又は看護師は、保健師籍、助産師籍又は看護師籍の登録の抹消を申請するときは、厚生労働大臣に申請書を提出しなければならない。<br>２ 准看護師は、准看護師籍の登録の抹消を申請するときは、免許を与えた都道府県知事に申請書を提出しなければならない。<br>３ 業務に従事する保健師、助産師若しくは看護師又は准看護師が前二項の規定による申請をする場合には、就業地の都道府県知事を経由しなければならない。ただし、当該准看護師が情報通信技術活用法第六条第一項の規定により前項の規定による申請を電子情報処理組織を使用して行うときは、当該就業地の都道府県知事を経由することを要しない。 |
